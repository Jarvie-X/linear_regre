# S-02 — Train regression model

## Technical implementation spec

### Goal

Train a linear regression model from the prepared learning examples and
produce one prediction for every held-out evaluation example, without any
interactive or customer-provided input.

### Design

- Add a `TrainedRegression` result type containing the fitted scikit-learn
  `LinearRegression`, the evaluation predictions, and the expected evaluation
  targets.
- `train_regression_model` accepts the `DiabetesDataset` returned by S-01,
  fits `sklearn.linear_model.LinearRegression` on `X_learning` and
  `y_learning`, and predicts against `X_evaluation`.
- Validate that the fitted output has exactly one prediction per held-out
  example.  An empty evaluation set is rejected rather than silently
  producing an incomplete result.
- Extend the existing input-free module workflow to prepare the fixed dataset,
  train the model, and report the number of generated predictions. Running it
  repeatedly uses the same prepared examples and requires no manual data
  entry.

### Validation

Tests will assert that the fitted model is usable, that predictions cover all
held-out examples, that training is repeatable for the fixed preparation, and
that the command-line workflow completes twice without input.

### Verification command

```sh
PYTHONPATH=src python -m linear_regre.diabetes
PYTHONPATH=src python -m linear_regre.diabetes
python -m pytest
```
