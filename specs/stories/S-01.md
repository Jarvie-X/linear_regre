# S-01 — Prepare Diabetes dataset

## Technical implementation spec

### Goal

Provide a repeatable, input-free workflow that loads scikit-learn's built-in
Diabetes regression dataset and returns two disjoint groups of examples: a
learning set and a held-out evaluation set.

### Design

- `linear_regre.diabetes.prepare_diabetes_dataset` calls
  `sklearn.datasets.load_diabetes` with its built-in defaults; it does not
  accept a file path or require customer data.
- The examples are split with `train_test_split`, using a documented default
  evaluation fraction of 20% and a fixed random seed.  A fixed seed makes
  repeated preparation consistent while retaining a held-out group.
- The result is a typed `DiabetesDataset` value containing feature matrices,
  target vectors, and the source/example counts.  The loader's success is
  observable through the CLI's `Loaded Diabetes dataset successfully` message.
- The CLI (`python -m linear_regre.diabetes`) runs one preparation and prints
  the learning/evaluation sizes.  It has no required arguments or inputs.

### Validation

The implementation validates that the loaded feature and target lengths match,
that both groups are non-empty, and that the split accounts for every source
example.  Tests also prepare the dataset twice and compare all returned values
to verify deterministic, repeatable preparation and distinct groups.

### Verification command

```sh
PYTHONPATH=src python -m linear_regre.diabetes
PYTHONPATH=src python -m linear_regre.diabetes
python -m pytest
```
