# S-03 — Measure prediction quality

## Technical implementation spec

### Goal

Report numeric prediction-quality measures for every completed regression run,
using only predictions and actual outcomes from the held-out evaluation set.

### Design

- Add a `PredictionQuality` result value containing mean absolute error (MAE),
  mean squared error (MSE), root mean squared error (RMSE), and R-squared
  (R²).  These measures are numeric and provide both an error scale and a
  simple goodness-of-fit interpretation.
- Add `measure_prediction_quality` to calculate the measures from the
  `TrainedRegression` result's `predictions` and `evaluation_targets`.  It
  validates that both are non-empty, one-dimensional, equal-length, and
  finite.  It does not use learning examples or the fitted model's training
  score.
- Extend the input-free module workflow so that a completed training run
  always measures and prints the held-out results, including the number of
  evaluation examples and all four numeric measures.

### Validation

Tests will verify the measures against known held-out predictions and actual
outcomes, that malformed or empty evaluation data is rejected, that learning
examples cannot affect the result, and that the command-line workflow reports
numeric held-out measures.

### Verification command

```sh
PYTHONPATH=src python -m linear_regre.diabetes
python -m pytest
```
